How to submit

  1. Run your reader on P-mod-open v0 and package the predictions in a heocr-bench ZIP.
  2. Open a GitHub pull request with the ZIP and a JSON receipt listing the reader, version, licence, open or closed weights, a public link and the ZIP checksum.
  3. Read the score comment and request review. One entry per reader and version is accepted. After the lead merges it, the row is self-submitted, unverified until HeOCR reruns it.

Submission instructions and example

איך מגישים תוצאות?

  1. הריצו את מנוע הזיהוי על P-mod-open v0 והכינו קובץ ZIP בפורמט heocr-bench.
  2. פתחו בקשת מיזוג ב־GitHub עם קובץ התחזיות וקובץ JSON ובו שם המנוע, גרסה, רישיון, משקולות פתוחות או סגורות, קישור ציבורי וסכום הביקורת של הקובץ.
  3. בדקו את תגובת הניקוד ובקשו בדיקה. אפשר להגיש פעם אחת לכל צמד של מנוע וגרסה. לאחר המיזוג, התוצאה תסומן ״הוגש עצמאית, טרם אומת״ עד להרצה חוזרת של HeOCR.
